I made this website by using html,css and some js . it is a simple website as i mainly focused in the layout.

movie Explorer lets users explore different categories of movies and view basic information such as the movie poster, title, genre, release year, and rating.

##  Features

 home page with featured movies
 trending Movies section
 most Popular Movies section
 highest Rated Movies section
 movie cards with:

  * Poster
  * Title
  * Genre
  * Release year
  * Rating
*  Simple and clean layout
*  Dark sidebar with a light main content area

##  Technologies Used

HTML — Website structure
CSS — Styling and layout
JavaScript — Search functionality and API requests
