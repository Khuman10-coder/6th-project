#  Movie Explorer

A simple movie discovery website built as a learning project using **HTML, CSS, and JavaScript**.

Movie Explorer lets users explore different categories of movies and view basic information such as the movie poster, title, genre, release year, and rating.

##  Features

 Home page with featured movies
 Trending Movies section
 Most Popular Movies section
 Highest Rated Movies section
 Movie cards with:

  * Poster
  * Title
  * Genre
  * Release year
  * Rating
* 📱 Simple and clean layout
* 🎨 Dark sidebar with a light main content area

## 🛠️ Technologies Used

* **HTML** — Website structure
* **CSS** — Styling and layout
* **JavaScript** — Search functionality and API requests






## 🎨 Design

The website uses a dark navy sidebar and a light main content area to keep the interface simple and easy to navigate.

The navigation includes:

* Home
* Trending Movies
* Most Popular Movies
* Highest Rated Movies

* 🎨 Dark sidebar with a light main content area

* **CSS** — Styling and layout
* **JavaScript** — Search functionality and API requests
* **OMDb API** — Movie information

## 📂 Project Structure

```text
Movie-Explorer/
│
├── index.html
├── style.css
├── script.js
└── images/
    └── movie posters
```

## 🔎 Movie Search

The search feature uses JavaScript to send a request to the **OMDb API**.

The basic process is:

```text
User searches for a movie
        ↓
JavaScript gets the search text
        ↓
Request is sent to OMDb API
        ↓
Movie data is received
        ↓
Movie information is displayed on the page
```
